Initial release of `@vibewarz/replay-viewer` — React component package for
rendering vibewarz Curve replays from a JSONL event stream. Extracted from
the closed-source `apps/web` replay components so the OSS Python CLI's
`vibewarz replay --watch` and the platform's web UI render through the same
code. API is unstable in 0.x; expect breaking changes between minor versions
until 1.0.
